# ErdetTutorial

Erdetspill modding tutorial

## Instructions

### Modloader

Download the Erdetspill Modloader by Goglesser: https://github.com/Goglesser/Erdetmodloader/releases

Move the files in the zip-file to your erdetspill steamapp folder (usually located at "\Program Files (x86)\Steam\steamapps\common\erdetspill")

Install by running the INSTALL_MODLOADER.bat file

### Tutorial mod

Download the ErdetTutorial mod

Place the zip file (don't un-zip) in the "mods" folder

Toggle the Pink Sky in the video settings of erdetspill (on by default)
